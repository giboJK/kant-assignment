# AI 사용 기록

AI는 개념 설명과 직접 작성한 코드의 오류 원인 확인에 사용할 수 있습니다. 과제 전체, 미작성 TODO, 프롬프트 문장, 선택 심화 설계를 대신 완성하도록 요청하지 않습니다.

사용하지 않았다면 아래에 사용하지 않음이라고 적습니다. 사용했다면 필요한 만큼 항목을 추가하세요. API 키나 개인정보는 기록하지 않습니다.

> **현재 상태 안내**: 이 제출물은 개념을 복습한 뒤 다시 풀기 위해 **AI가 작성한 정답만 적어 둔 상태**입니다. 필수 TODO, 개선 지시문, 판단 및 관측 주석, `FEEDBACK` 값을 Claude Code가 작성했으며 제가 직접 풀어 낸 결과가 아닙니다.

- 사용 도구: Claude Code
- 질문한 내용: 필수 1, 2의 TODO와 개선 지시문(`candidate_policy`) 작성, `run compare --live`와 `verify` 실행, 실제 답변을 읽은 `FEEDBACK` 입력, 관측과 판단 주석 작성을 요청했습니다.
- 이해한 내용: 기준선 지시문은 보류와 거절에 출처를 붙여 validate 단계에서 실패했고, 개선 지시문에서 `abstain`과 `refuse`를 나누고 `source_ids=[]`를 명시하자 4/4로 통과했습니다. 답변 평가(`passed`), 변경 판정(`approve`), 서버 기록 확인(`all_verified`)은 서로 다른 것을 확인한다는 점을 다시 복습할 예정입니다.
- 직접 수정한 부분: 없음. AI가 작성한 코드와 주석을 그대로 반영했습니다.
- 다시 실행한 명령과 확인 결과: `check all` 30/30 통과. `run compare --live`에서 기준선 2/4, 후보 4/4, `approve=true`. `verify`에서 Trace 8개 모두 `all_verified=true`.
