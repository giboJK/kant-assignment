# AI 사용 기록

AI는 개념 질문과 직접 작성한 코드의 오류 원인 확인에 사용할 수 있습니다. 과제 전체, 미작성 빈칸, 선택 심화의 설계나 정답을 대신 작성하도록 요청하지 않습니다. 설명을 이해한 뒤 직접 수정하고 다시 검사하세요.

사용하지 않았다면 아래에 사용하지 않음이라고 적습니다. 사용했다면 필요한 만큼 행을 추가하세요. API 키와 개인 정보는 기록하지 않습니다.

> **현재 상태 안내**: 이 제출물은 개념을 복습한 뒤 다시 풀기 위해 **AI가 작성한 정답만 적어 둔 상태**입니다. 필수 빈칸, 이유 주석, 관측 주석을 Claude Code가 작성했으며 제가 직접 풀어 낸 결과가 아닙니다. 선택 심화는 작성하지 않았습니다.

| 사용 도구 | 질문 | 이해한 내용 | 직접 수정한 부분 | 다시 실행한 명령과 결과 |
|---|---|---|---|---|
| Claude Code | 필수 1, 2의 빈칸 10곳에 들어갈 코드와 빈칸별 설명 작성 요청 | 사용 가능 여부를 먼저 거른 뒤 우선순위로 정렬해야 하는 이유, 기억 저장과 조회에 사본이 필요한 이유, 자료를 developer가 아닌 user 참고 데이터로 두는 이유, 예산을 넘는 순간 멈춰야 연속된 최근 턴만 남는다는 점 (복습 예정) | 없음. AI가 작성한 코드를 그대로 반영했습니다 | `check all` 16/16 통과 |
| Claude Code | `run compare --live`, `run cache --live` 실행과 관측 주석 작성 요청 | 최근 대화만 남기면 승인조건이 빠져 모델이 공통 정책 문장으로 잘못 채웠고, 요약을 함께 넣으면 세 사실이 보존됨. 캐시 읽기 1228토큰으로 입력 비용이 약 72% 줄었고 쓰기 토큰은 관측되지 않음 | 없음 | compare live: 전체 3/3, 최근 0/3, 요약+최근 3/3. cache live: cached_tokens 0→1228→1228 |
